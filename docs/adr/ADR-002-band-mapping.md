# ADR-002: Band Mapping for Score Transformation

## Context
ในการแปลง Quality Index $q \in [0, 1]$ จาก pairwise comparisons ไปเป็นคะแนนผลงาน หากใช้วิธี **Sum-to-one Normalization** ($\sum \text{score} = 1$) ในห้องที่มี 10 กลุ่ม แต่ละกลุ่มจะได้คะแนนเฉลี่ย $\approx 0.1$ เมื่อคูณคะแนนเต็ม 15 ทุกกลุ่มจะได้เพียง 1.5 คะแนน ซึ่งขัดกับธรรมชาติของการประเมินผลการเรียนรู้

การใช้ percentile rank หรือ z-score ก็บังคับให้มีผู้ได้เกรดต่ำเสมอ แม้ทุกกลุ่มจะทำผลงานได้ตามเกณฑ์มาตรฐาน

## Decision
ใช้ **Band Mapping** ในการแปลงค่า $q(i,c)$ เป็นสัดส่วนคะแนน:
$$\text{score\_ratio}(i,c) = \text{floor} + (\text{ceiling} - \text{floor}) \times q(i,c)$$

ค่าตั้งต้น:
- `floor` = 0.60 (60% ฐานขั้นต่ำสำหรับทุกกลุ่มที่ส่งงาน)
- `ceiling` = 1.00 (100% เพดานสูงสุด)

สามารถปรับแต่งค่า `floor` และ `ceiling` ได้ต่อ assignment หากอาจารย์ต้องการขยายช่วงการแยกแยะ

## Consequences
- **Positive**: เข้าใจง่าย โปร่งใส และอธิบายให้นักศึกษาฟังได้ทันทีโดยไม่มีสูตรซับซ้อน (ต่างจาก Bradley-Terry)
- **Positive**: ทุกกลุ่มที่ส่งงานตามมาตรฐานจะได้รับคะแนนฐานอย่างน้อย 60% ส่วน 40% ที่เหลือคือคะแนนจัดอันดับเชิงเปรียบเทียบ
- **Trade-off**: ไม่ได้ปรับแก้สำหรับเครือข่าย comparison ที่ไม่สมดุลเท่ากับแบบจำลองทางสถิติขั้นสูงอย่าง Bradley-Terry แต่ชดเชยด้วยการการันตี Balanced Coverage ของ Pairing Engine
