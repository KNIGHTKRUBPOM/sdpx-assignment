# ADR-001: 6-Point Forced Choice Scale Without Neutral Option

## Context
ในการประเมินแบบ Pairwise comparison ปัญหาคลาสสิกของแบบประเมินที่มีตัวเลือก "เท่ากัน" (Neutral option หรือ Tied option เช่น สเกล 5 ระดับ หรือ 7 ระดับที่มีค่ากลาง) คือผู้ประเมินมักเกิด **Central Tendency Bias** โดยเลือกตรงกลางเมื่อไม่อยากใช้ความคิดเปรียบเทียบเชิงลึก ส่งผลให้ข้อมูลที่ได้ไม่สามารถแยกแยะคุณภาพของผลงานได้อย่างมีนัยสำคัญ

## Decision
กำหนดให้ระบบ PairEval ใช้ **6-point forced choice** โดยไม่มีตัวเลือกตรงกลาง:
1. ซ้ายดีกว่ามาก (Points: 1.0 vs 0.0)
2. ซ้ายดีกว่า (Points: 0.8 vs 0.2)
3. ซ้ายดีกว่าเล็กน้อย (Points: 0.6 vs 0.4)
4. ขวาดีกว่าเล็กน้อย (Points: 0.4 vs 0.6)
5. ขวาดีกว่า (Points: 0.2 vs 0.8)
6. ขวาดีกว่ามาก (Points: 0.0 vs 1.0)

ทุกปุ่มตัวเลือกต้องแสดง Text Label ชัดเจน ไม่ใช้เพียงตัวเลข เพื่อรองรับ Accessibility (WCAG 2.2 AA)

## Consequences
- **Positive**: บังคับให้ผู้ประเมินต้องชั่งน้ำหนักและตัดสินใจว่าฝั่งใดดีกว่าแม้เพียงเล็กน้อย ขจัด central tendency bias
- **Positive**: แปลงเป็นคะแนนสมมาตร (Symmetric point values) ที่คำนวณเข้า weighted mean ได้อย่างเที่ยงตรง
- **Trade-off**: ผู้ประเมินอาจรู้สึกว่าถูกบีบให้เลือกในกรณีที่งานใกล้เคียงกันมาก แก้ไขโดยการมีตัวเลือก "ดีกว่าเล็กน้อย" (0.6 / 0.4) เพื่อสะท้อนความต่างที่น้อยที่สุด
