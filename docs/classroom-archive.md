# เก็บห้องเรียนถาวร (FR-CLASS-07)

เจ้าของห้อง (OWNER) เปิดห้องเรียน → จัดการห้องเรียน → **เก็บห้องเรียนถาวร** แล้วพิมพ์ชื่อห้องให้ตรงและระบุเหตุผลอย่างน้อย 3 ตัวอักษร ยกเลิกได้ก่อนยืนยัน ห้องที่เก็บแล้วอยู่ในรายการพับ “ห้องเรียนที่เก็บถาวร” บน dashboard และเปิดอ่านได้ผ่านลิงก์เดิม

- เป็นการเก็บแบบอ่านอย่างเดียว ไม่ใช่การลบข้อมูล คะแนน snapshot คำตอบ สมาชิก และ audit เดิมยังอยู่
- ทุกงานในห้องหยุดรับการแก้ไขและคำตอบเพิ่มทันที แม้สถานะงานเดิมเป็น OPEN; ไม่เปลี่ยนสูตรคะแนนหรือสถานะงานเดิม
- อาจารย์ยังอ่านรายงานและ export ได้ นักศึกษาอ่านคำตอบ/คะแนนของตนเองภายใต้สิทธิ์และเกณฑ์ anonymity เดิม
- เซิร์ฟเวอร์ตรวจสมาชิกและล็อกแถวห้องเดียวกับทุก mutation ก่อนตั้ง archivedAt เพื่อป้องกันการเขียนพร้อมกัน การเขียนหลังเก็บห้องตอบ 409 CLASSROOM_ARCHIVED
- บันทึก ARCHIVE_CLASSROOM พร้อมผู้กระทำ เวลา request ID เหตุผล และค่าก่อน/หลัง ใน audit แบบ append-only
- ไม่มี API ลบข้อมูลหรือเปิดห้องกลับในรอบนี้ ไม่ควรใช้กับงานที่ยังต้องส่งคำตอบ

อ้างอิง [PRD](https://github.com/CE-SDPX/SDPX-AI/blob/main/project-ideas/pairwise_evaluation_prd.md): FR-CLASS-07 (archive/read-only), FR-AUTHZ-01/02 (ตรวจสิทธิ์ทุกคำขอ), FR-AUDIT-01/03 (เหตุผล/ประวัติแก้ย้อนหลังไม่ได้), FR-ANON-01 (สิทธิ์เปิดเผยคะแนนเดิม)
